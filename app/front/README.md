# Authentication front

React + MUI client built with [Vite+](https://viteplus.dev) (`vite-plus`), pnpm and Node 26.

## Scripts

| Command                | Description                                              |
| ---------------------- | -------------------------------------------------------- |
| `pnpm install`         | Install dependencies (pnpm 12)                           |
| `pnpm dev`             | Start the dev server on http://localhost:3001            |
| `pnpm build`           | Build the app into `build/`                              |
| `pnpm check`           | Format check, lint (Oxlint, type-aware) and type check   |
| `pnpm lint`            | Lint only                                                |
| `pnpm fmt`             | Format the sources (Oxfmt)                               |
| `pnpm refresh-clients` | Regenerate the API client from the backend swagger (nswag) |
